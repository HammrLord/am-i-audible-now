# Am I Audible Now? Dissecting Prosody in Neural Audio Codecs

Project page for the paper by Nikunj Gupta, Shreshth Rai, Kartik Sharma, and
Dinesh Kumar Vishwakarma (Delhi Technological University).

## Layout

```
index.html           page content
static/css/index.css page styles (Bulma is vendored alongside)
static/js/index.js   navbar, carousel, and the interactive chart
static/images/       figures from the paper
static/pdf/          the paper
```

The numbers behind the interactive chart live in the `CODECS` object at the top
of `static/js/index.js` and are copied from the tables in the paper.
